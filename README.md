# **InfraFlowOps: Automating EC2, SSL, and CI/CD for Static Websites**

## **Overview**
InfraFlowOps is a Python-based automation tool that provisions AWS EC2 instances, configures SSL certificates for Nginx, and deploys Dockerized static websites using CI/CD pipelines. It streamlines infrastructure management and deployment processes for DevOps workflows.

## **Features**
- Automates EC2 instance provisioning using AWS Boto3.
- Configures SSL certificates for Nginx with `ssl_conf.py`.
- Builds, tags, and pushes Docker images to Docker Hub or AWS ECR.
- Deploys Dockerized applications on EC2 instances.
- Enables CI/CD operations with `cicd.py` for seamless updates to deployed applications.

## **File Descriptions**

### **1. `autoinfra.py`**
Automates infrastructure provisioning and application deployment:
- Provisions EC2 instances.
- Sets up Nginx and Docker on the server.
- Builds Docker images locally and pushes them to the specified registry.
- Deploys the Docker container to the EC2 instance.
- Supports planning and termination of resources.

#### **Key Functions**
- `plan_resources()`: Simulates resource creation without execution.
- `create_ec2_instance()`: Creates an EC2 instance and returns the public IP.
- `docker_login()`: Authenticates with Docker Hub or AWS ECR.
- `build_and_tag_docker_image()`: Builds and tags the Docker image.
- `pull_and_run_docker_image()`: Pulls and runs the Docker container on the EC2 instance.
- `terminate_ec2_instance()`: Terminates the EC2 instance.

---

### **2. `ssl_conf.py`**
Automates SSL configuration for Nginx:
- Transfers SSL certificate and private key files to the EC2 instance.
- Updates the Nginx configuration to enable HTTPS.
- Redirects HTTP traffic to HTTPS.

#### **Key Functions**
- `get_public_ip()`: Reads the EC2 public IP from a file.
- `transfer_ssl_files()`: Transfers SSL files to the EC2 instance and sets proper permissions.
- `update_nginx_config()`: Configures Nginx for HTTPS with the SSL certificate and private key.

---

### **3. `cicd.py`**
Handles CI/CD operations for deployed applications:
- Automates Docker login, build, and push operations.
- Pulls and runs the latest Docker containers on the EC2 instance.
- Removes outdated containers and images during the update.

#### **Key Functions**
- `docker_login()`: Logs in to the container registry.
- `build_and_tag_docker_image()`: Builds and tags Docker images for deployment.
- `push_docker_image()`: Pushes Docker images to the registry.
- `update_docker_container()`: Updates the Docker container on the EC2 instance.

---

## **Setup**

### **Requirements**
- Python 3.x
- AWS CLI configured with proper credentials
- Docker installed locally
- Required Python packages:
  ```bash
  pip install boto3 paramiko python-dotenv
  ```

### **Environment Variables**
Create a `.env` file with the following variables:
```ini
SUBDOMAIN=your-subdomain.example.com
DOCKERHUB_USERNAME=your-dockerhub-username
DOCKERHUB_PASSWORD=your-dockerhub-password
KEY_FILE_PATH=/path/to/your/aws-private-key.pem
LOCAL_SSL_CERT=/path/to/ssl-certificate.crt
LOCAL_SSL_KEY=/path/to/ssl-private-key.key
REGISTRY_TYPE=dockerhub  # or 'ecr' for AWS Elastic Container Registry
CODE_DIR=/path/to/your/code/directory
```

## **Usage**

### **1. Plan Infrastructure**
Simulate resource creation:
```bash
python autoinfra.py --plan
```

### **2. Deploy Infrastructure and Application**
Create resources, set up SSL, and deploy the application:
```bash
python autoinfra.py --auto_approve
```

### **3. Update Application**
Update Docker containers on the EC2 instance:
```bash
python cicd.py
```

### **4. Terminate Infrastructure**
Destroy the EC2 instance:
```bash
python autoinfra.py --destroy
```

---

## **Project Workflow**
1. **Provision EC2**: `autoinfra.py` provisions an EC2 instance and sets up Nginx and Docker.
2. **Deploy SSL**: `ssl_conf.py` transfers SSL certificates and updates the Nginx configuration.
3. **Build and Push Docker Image**: Locally build the Docker image and push it to the registry.
4. **Deploy Application**: `autoinfra.py` deploys the Dockerized application on the EC2 instance.
5. **CI/CD**: `cicd.py` handles future updates to the application, ensuring smooth delivery.

---

## **Example Workflow**
1. Provision EC2 and deploy:
   ```bash
   python autoinfra.py --auto_approve
   ```

2. Verify HTTPS configuration:
   ```bash
   curl -v https://<your-subdomain>
   ```

3. Update application code:
   - Modify the application in the `CODE_DIR`.
   - Run:
     ```bash
     python cicd.py
     ```

4. Terminate resources when no longer needed:
   ```bash
   python autoinfra.py --destroy
   ```

## **Logs and Troubleshooting**
Logs are generated by each script for debugging:
- **Nginx Logs**: `/var/log/nginx/`
- **Docker Logs**: `docker logs <container-name>`

For issues, check:
1. **AWS Security Groups**: Ensure ports `80` and `443` are open.
2. **SSL Configuration**: Verify certificates are valid using OpenSSL:
   ```bash
   openssl x509 -in <certificate>.crt -text -noout
   ```
